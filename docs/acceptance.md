## Аналитические примеры для авторских CPU-тестов

- OBB center0, halfExtents(2,0.5,2), orientationIdentity: верхняя граньY=0.5.
  Sphere center(0,1,0), radius0.5 касается грани, normal+Y, penetration0.
  CenterY=0.9 даёт penetration0.1 и коррекцию вверх; отдаление от грани не блокируется.
- Центр внутри симметричного OBB и равные расстояния до граней: выбрать+X по tie-break,
  а не нормализовать zero vector и не получить NaN.
- Локальные преобразования: world→local→world для повёрнутого OBB восстанавливают точку
  с допустимой ошибкой≤1e-4 для координат по модулю≤100; вне этого диапазона допуск
  учитывает масштаб и float ULP. Нормаль наклона20° имеет Y≈0.93969.
- При JumpSpeed6 и Gravity18 непрерывная оценка вершины: t=1/3с, h=1единица;
  полунеявный Euler с dt1/120 достигает h≈0.975. CPU-тест вычисляет независимую дискретную
  сумму, не требует точного непрерывного1.0 и проверяет обоснованный допуск.
- Из состояния покоя при move acceleration20, dt1/120, AirControlFactor=1 и без контактов: ΔvX=1/6,
  Δx=1/720≈0.00138889. Это проверка выбранного интегратора, не копирование всего решателя.
- При speed4.5, boost1.8 максимум8.1. Максимальная длина горизонтального перемещения
  одного tick0.0675, меньшеRadius/4=0.125; падение30 требует0.25 и минимум2подшага.
  Пример балки: offset2, halfExtents(1,0.1,0.1), ω2рад/с; bound tipradius≈3.01,
  путь за tick≈0.0502. При очень большом ω комбинация обязана отклониться заранее.
- Runner: два кадра dt/2 дают один tick; кадр3dt даёт три ticks с JumpPressed только в первом;
  Clear между нажатиями и tick удаляет Jump. При frame0.1 и budget8 отбрасываются только
  полные оставшиеся ticks, остаток меньшеdt сохраняется.
- После Restart SessionId другой, Tick0, event queue пуста; сохранившийся старый snapshot не изменился.

Реальные edge/CCD/hazard tests обязан добавить исполнитель и независимый QA. Примеры не доказывают
реализованный решатель и не заменяют прохождение level1/level2. Непрохождение обязательного BA-ID —
блокирующий дефект, а не повод отметить задачу Done по наличию интерфейсов.
