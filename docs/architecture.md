# Архитектура

Игра использует движок как внешнюю библиотеку. Обновление версии движка — отдельное изменение gitlink с проверками.

```text
Platformer.App ──> Platformer.Core (стандартная .NET)
      │
      ├────────> Engine3D.Core
      └────────> Engine3D.OpenGL ──> Engine3D.Core
Platformer.Tests ──> Platformer.App / Platformer.Core
```

## Реализованный каркас

- Core содержит неизменяемый технический макет платформ: центр и полные размеры.
- App переводит макет в SceneObject, переиспользует один MeshData, создаёт камеру и Engine.
- `Engine.Create → Run(scene, camera, onUpdate) → Dispose` выполняются на одном потоке.
- `--help` не создаёт окно; `--smoke` закрывается после трёх показанных кадров.
- Камера смотрит сбоку на плоскость X/Y. Escape в активном окне штатно закрывает preview через RequestClose.
- CPU-тесты проверяют адаптацию координат/размеров, камеру, независимость сцен и общий mesh.

## Направление дальнейшей реализации

Состояние персонажа, движение, коллизии и правила прохождения принадлежат Core.
App передаёт абстрактную команду игрока в Core и синхронизирует scene transforms после обновления.
Шаг симуляции, ограничения delta time, геометрия коллизий и поведение камеры должны быть
определены до реализации; текущий каркас этих контрактов не задаёт.

## Клавиатурный ввод

Сигнатура callback `Action<float>` сохранена. Внутри него `engine.Input` возвращает
неизменяемый InputSnapshot с фокусом, IsDown, WasPressed и WasReleased для InputKey.
Публичный контракт не раскрывает окно или OpenTK-типы. Первый пакет активации подавляется;
при потере фокуса удержания и фронты очищаются. Повторный sim tick не должен повторять одно нажатие.
Игра должна сама очищать очередь команд/накопленное время при потере фокуса.
Полный контракт находится в `external/engine/docs/keyboard-input.md`.
Расширение добавлено в upstream по отдельному поручению через PR; обновления движка остаются отдельными задачами.
Прямые OpenTK/GL-вызовы, reflection или создание второго окна для ввода не допускаются.

## Соглашения

Правая система, Y вверх; в System.Numerics row-vector `model = scale * rotation * translation`.
Поправку глубины и загрузку матриц выполняет движок; игра её не дублирует.
GPU-ресурсами владеет Engine; игровые данные и Scene не освобождают GPU handles.
Материалы и меши разделяются только там, где их совместное использование предусмотрено.
