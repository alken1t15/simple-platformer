# Ярлык и значок игры

Общие [PNG и ICO](../assets/branding/README.md) входят в репозиторий. Linux-ярлык
создаётся для текущего пользователя и ссылается на собранную игру в вашем клоне.
Личные Windows-лаунчеры, пути и настройки разработчиков не нужны.

## Linux

Сначала выполните сборку по [README](../README.md#запуск). Нужны Python 3, Bash,
`setsid` (util-linux) и `dotnet` (.NET 10 Runtime) в PATH терминала установщика.
Установка не скачивает пакеты, не собирает проект и не требует `sudo`.

```sh
python3 scripts/install_desktop.py
```

В меню приложений появится **Ball Adventure** с фирменным значком. Команда запускает
`scripts/Play.sh --visual`, без терминального окна. Логи — в `artifacts/run/` клона.
Установщик сохраняет путь к каталогу найденного `dotnet`, чтобы запуск из меню
не зависел от добавлений в PATH интерактивного терминала.

Дополнительно на рабочий стол:

```sh
python3 scripts/install_desktop.py --desktop
```

Для этой опции нужен `xdg-user-dir` из `xdg-user-dirs` и настроенная папка Desktop.
Некоторые окружения требуют вручную выбрать «Разрешить запуск»/«Доверять» в свойствах
файла. GNOME и другие оболочки могут не показывать ярлыки на рабочем столе вообще;
запуск из меню приложений остаётся доступен. Установщик не меняет политики доверия оболочки.

Файлы устанавливаются в `${XDG_DATA_HOME:-$HOME/.local/share}`:

- `applications/org.alken1t15.BallAdventure.desktop` — запись меню;
- `ball-adventure/launch.sh` — небольшой запускной скрипт.

Опция `--desktop` также создаёт `Ball Adventure.desktop` в папке, возвращаемой
`xdg-user-dir DESKTOP`. Повторная установка обновляет собственные созданные файлы;
чужой файл или символьную ссылку с таким именем установщик не перезаписывает.
Для удаления удалите эти созданные файлы. Игровые сохранения при этом не затрагиваются.

**После переноса клона или установки .NET в другой каталог выполните установку заново.**
Ярлык содержит абсолютные пути вашей машины, но они генерируются локально, а не
хранятся в репозитории. Новые экземпляры игры лаунчер не объединяет: закройте текущую
игру перед повторным запуском. Значок в меню/ярлыке не заменяет значок окна движка.

## Windows

Настройка .NET/OpenAL и запуск описаны в [windows-wsl.md](windows-wsl.md).
Для ярлыка уже собранной игры укажите полный путь к Windows `dotnet.exe`, затем
в аргументах полный путь к `Platformer.App.dll` и `--visual`. В свойствах ярлыка
«Сменить значок» выберите [ball-adventure.ico](../assets/branding/ball-adventure.ico).
OpenAL Soft должен быть установлен по инструкции; Linux-установщик `.desktop`
на Windows не выполняется. Проверенный личный Windows-ярлык пользователя остаётся локальным.

## Проверки

`python3 scripts/test_desktop_installer.py` проверяет установку и повторную установку,
отказ без сборки/при конфликте, настоящий `gio launch` с пробелами, Unicode, `%`,
кавычками, `$`, обратными кавычками и обратным слешем в путях. Используется временный
каталог и подставной `dotnet`, который фиксирует аргументы, без запуска видимой игры.
Если установлен `desktop-file-validate`, проверяется и формат записи.

`python3 scripts/check_launch_x11.py --desktop` запускается отдельно под Xvfb:
реальная игра открывается через установленный `.desktop` и `gio`, остаётся жива после
Ctrl+C исходного терминала, штатно закрывается. Это автоматическая X11-проверка,
не проверка меню конкретного рабочего окружения, физического монитора или слышимости.

Формат записи соответствует [Desktop Entry Specification](https://specifications.freedesktop.org/desktop-entry/latest/).
