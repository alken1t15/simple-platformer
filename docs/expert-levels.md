Продолжение расширения от 12.11.2026. Пять испытаний из
[первого пакета](five-challenge-levels.md) сохранены. После Temple Gauntlet идут:

| № | Уровень / ID | Испытание |
|---|---|---|
| 10 | Pendulum Gorge / `pendulum-gorge` | Три камня на канатах над узкими мостами, разные фазы качания, поворот по узкой шейке и завершающий разрыв 1.8 |
| 11 | Piston Foundry / `piston-foundry` | Три поперечных толкателя с разными фазами, подъём и серия прыжков по плитам, разрушающимся через 1.25 и 1.15 с |
| 12 | Clockwork Summit / `clockwork-summit` | Подъём, маятник, диагональный мост шириной 1, толкатель, смертельный барьер и два прыжка с набором высоты через разрывы 1.6 |

Sky Storm остаётся последним, теперь №13. Каждый новый уровень содержит 12 монет;
в каталоге **162 монеты** и максимум **39 звёзд**. Первые двенадцать локаций доступны
через Levels сразу. Sky Storm по-прежнему требует 12 звёзд только на исходных первых
четырёх. Старые результаты и формат сохранений не меняются.

## Новые элементы

**Маятник.** Каменный груз с бирюзовыми прожилками подвешен на канате к деревянной
перекладине. Две стойки стоят на собственных основаниях вне траектории камня.
Груз качается туда-обратно, замедляясь у крайних положений. Для прохода надо дождаться,
пока камень уйдёт в сторону. Контакт отбрасывает шар, а падение может закончить попытку.
Канат — тонкая декорация; груз и стойки имеют физические OBB, согласованные с рендером.

**Поперечный толкатель.** Деревянный блок с канатными обвязками ездит поперёк дорожки
по металлической направляющей. На концах хода он разворачивается; проход открывается,
когда блок уходит в сторону. Попадание отбрасывает. Направляющая находится под дорогой,
декоративные корпуса — за пределами хода; они не маскируют препятствие на пути шара.

Широкие площадки разделяют опасные секции и позволяют ждать. Это места передышки,
а не checkpoints: R/Restart возвращает на старт. Все разрывы проходимы обычным прыжком
без обязательного boost. Баланс сложности требует оценки игроком.

## Контракт движения и столкновений

`HazardDefinition.MotionKind` по умолчанию `Rotation`: прежние опасности сохраняют
формулу движения. `AngularSpeed` для новых режимов означает частоту фазы в рад/с,
`InitialAngle` — начальную фазу. `Amplitude` задаёт радианы для `Pendulum` и расстояние
для `Shuttle`.

- Pendulum: угол = `Amplitude * sin(AngularSpeed * t + InitialAngle)`;
  центр и ориентация поворачиваются вокруг Pivot/Axis.
- Shuttle: центр = `Pivot + CenterOffset + Axis * Amplitude * sin(phase)`;
  ориентация остаётся InitialOrientation.
- Скорость для CCD/бюджета — максимум скорости любой вершины, с учётом амплитуды.
  Для отбрасывания используется мгновенная скорость, включая смену направления.

Время берётся только из fixed-step GameSession. Пауза замораживает фазу; Restart
восстанавливает исходную. Отменённый при отскоке Path не собирает монеты/финиш.
Core использует стандартную .NET; Presenter — только прежний публичный API движка.
Размещение декоративных островов учитывает полный ход новых механизмов, чтобы камни
и толкатели не проходили сквозь пальмы/домики вне границ дорожки.
Движок и его gitlink не изменены.

## Проверки и ручной сценарий

`ExpertObstacleTests` проверяет крайние положения/разворот маятника, производную
движения, консервативную скорость, контакт между непересекающимися концами tick,
превышение бюджета, отбрасывание стоящего шара, reset/паузу и согласованность поз.
Камень не пересекает собственные стойки. `ChallengeLevelTests` проходит новые уровни
с 12/12 монетами через настоящий ввод host в обоих оформлениях. Полный production
маршрут проходит все 13 уровней, собирает 162/162 монет и проверяет переходы/аудиособытия.
Все 13 карточек и Back проверяются при 800×450, 1280×720 и 1920×1080.

При ручной проверке открыть Levels → 10–12: дождаться крайнего положения каждого
препятствия, пройти мост, проверить отбрасывание и R; открыть паузу при движении
камня и убедиться, что после Continue он продолжает ту же фазу. На Clockwork Summit
проверить прыжок над барьером, затем два прыжка вверх и выход по диагонали.
Исторические ручные PASS прежних уровней не относятся к этим маршрутам.
