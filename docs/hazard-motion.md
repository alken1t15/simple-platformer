# Вращающаяся опасность

`HazardMotion.Evaluate` получает данные балки и время симуляции, вычисляет поворот
вокруг мировой оси и возвращает общий `HazardPose` для физики и Presenter. При времени 0
восстанавливается начальная фаза. Preview использует эту позу и сбрасывает её при R.

`HazardCollision.IntersectsPath` проверяет непрерывную ломаную движения шара, включая
неподвижные участки. Для каждого интервала вычисляется поза в середине и верхняя граница
относительного перемещения шара и наиболее удалённой точки балки. Если зазор больше
границы, интервал безопасен; иначе он делится на части. Контакт возвращает true.
Если за предоставленный бюджет нельзя доказать результат, выдаётся исключение с ID
опасности, а не ложный результат false. Перед проверкой оценивается бюджет с учётом
длины пути шара, угловой скорости и радиуса вращения балки.

Пример для будущего GameSession:

```csharp
bool hit = HazardCollision.IntersectsPath(hazard, ballStepResult.Path, tickStartSeconds, settings);
HazardPose pose = HazardMotion.Evaluate(hazard, simulationSeconds);
```

При hit сеанс должен установить Failed до обработки монет и финиша. Интеграция
ожидает принятия GameSession из PR #29. Арена для второй локации и ручное прохождение
также остаются на интеграцию. Preview не является проверкой настоящего игрового сеанса.
