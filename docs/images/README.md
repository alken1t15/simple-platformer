в `main` как `f80240e476c77b99c4e320224a65389d1492ac2f`.

Снимки иллюстрируют оформление; они не подтверждают FPS, физический монитор или слышимость.

## Кадры Winter Expedition

[springlight-trail.png](springlight-trail.png) и [windward-journey.png](windward-journey.png)
сняты перед публикацией расширения Winter Expedition из его проверенной Release-сборки
(487 тестов). Использован тот же публичный renderer Engine3D в X11/Xvfb/Mesa и
GameScenePresenter реального каталога. Для обзора изменено только положение камеры;
физические данные уровня, монеты, механизмы и HUD не редактировались. На старте
неподвижный шар собирает первую монету, поэтому HUD показывает 1/18 или 1/17.
PNG скопированы без ретуши. Эти кадры не являются доказательством полного прохождения,
FPS, физического GPU или слышимости звука.
