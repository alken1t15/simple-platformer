# Объём и состояние

Подтверждённая задача: подготовить отдельный репозиторий игры, AGENTS.md, локальный
workflow, архитектуру, CI и защиту main, сохранив прежний репозиторий без изменений.

Подготовка включает подключение Engine v1.0.0, три проекта, макет сцены, CPU-проверки,
команду графического smoke и инструкции разработки. Это инфраструктурная основа.

До реализации игры нужно согласовать:

- формат платформера: ограничения движения и положение камеры;
- управление и способ получения ввода при текущем API движка;
- поведение прыжка, гравитации, коллизий и перезапуска;
- уровень, условия победы/поражения и минимальную приёмку;
- состав команды, сроки и распределение задач, если требуется календарный план.

Названия репозитория недостаточно для принятия этих решений. Макет из трёх платформ
не является утверждённым уровнем. Issues, назначения, Project и сроки в этой подготовке не создаются.
