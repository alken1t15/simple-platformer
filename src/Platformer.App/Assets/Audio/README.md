# Источник игровых WAV

Все пять файлов созданы процедурно скриптом проекта `scripts/generate_audio.py` (Codex).
Внешние записи/семплы/музыкальные произведения не используются.
Лицензия — MIT проекта; полный текст поставляется рядом в LICENSE.txt.

| Файл | Содержание | Формат |
|---|---|---|
| jump.wav | Восходящий короткий сигнал прыжка | PCM16 mono, 16000 Hz |
| coin.wav | Двухтональный звон монеты | PCM16 mono, 16000 Hz |
| fail.wav | Нисходящий сигнал поражения | PCM16 mono, 16000 Hz |
| finish.wav | Три восходящие ноты финиша | PCM16 mono, 16000 Hz |
| music.wav | Собственная последовательность тонов, loop 8 секунд | PCM16 mono, 16000 Hz |

Файлы и этот manifest копируются в build/publish. Event mapping/lifecycle описаны в
`docs/game-audio.md` исходного репозитория. Автоматическая проверка не заменяет прослушивание.
